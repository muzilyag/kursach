# Правила форматирования и линтинга Frontend

Для поддержания высокого качества кода, единого стиля и строгой типизации на фронтенде используется связка из нескольких инструментов.

## Стек инструментов
* **ESLint** — статический анализ кода, поиск логических ошибок и неиспользуемых переменных.
* **Prettier** — автоматическое форматирование кода (отступы, кавычки, точки с запятой).
* **vue-tsc** — строгая проверка типов TypeScript в `.ts` и `.vue` файлах.

---

## Команды

Все команды выполняются из директории `frontend/`.

**1. Проверка кода на ошибки (Линтинг):**
Поиск проблем в стиле кода и потенциальных багов без их автоматического исправления.
```bash
npm run lint
```
**2. Автоматическое форматирование кода (Prettier):**
Приведение всех файлов (.vue, .ts, .css) к единому стандарту оформления.
```bash
npm run format
```
**3. Проверка типизации TypeScript:**
Статический анализ типов во всем проекте (поиск ошибок, когда ожидается string, а передается number и т.д.). Рекомендуется запускать перед каждым билдом.
```bash
npm run type-check
```
